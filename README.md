# VALPRO

Overwolf Native starter using React, Vite, and `@valpro-labs/ui`.

## Prerequisites

- Windows with the Overwolf desktop client installed.
- An Overwolf account enabled for loading unpacked extensions.
- Node.js 20 or newer.

## Install

```powershell
npm install
```

## Build The Desktop Window

```powershell
npm run build
```

The background and React desktop windows are built into `dist/windows/`, which is the folder declared in `manifest.json`.

## Run In Overwolf

1. Run `npm run build`.
2. Open Overwolf.
3. Open Settings, then the Packages or Development Options screen.
4. Choose Load unpacked extension.
5. Select this folder: `f:\Code\valpro-labs\desktop`.
6. Launch `VALPRO` from the Overwolf dock.

The app starts from `dist/windows/background/background.html`, then opens the built React desktop window declared in `manifest.json`.
When VALORANT launches, Overwolf also starts the background window minimized, registers VALORANT game events, and records only while a match is active.
If the app reports `gameInfo: null` while VALORANT is open, reload the extension and restart VALORANT after Overwolf is running so the client can inject and detect the game.

## Browser Preview

```powershell
npm run dev
```

Open `http://127.0.0.1:5173/desktop/desktop.html`. The Overwolf APIs will be reported as unavailable in browser preview mode.

## Project Layout

- `manifest.json` declares app metadata, permissions, developer auto-refresh, and windows.
- `src/background/` contains the TypeScript Overwolf startup window and VALORANT auto-recording logic.
- `src/desktop/` contains the React desktop window source.
- `src/shared/` contains shared recording storage and app event subscriptions used by both windows.
- `dist/windows/` contains the built background and desktop windows generated by Vite.
- `assets/icons/` contains the dock/window icon assets referenced by the manifest.

## Event Flow

The background window publishes durable app events through `src/shared/app-events.ts`.
The desktop window subscribes to the same event feed for live activity, so future VALORANT events can be displayed without adding another cross-window channel.

## Next Steps

- Add an in-game window under `manifest.json > data.windows`.
- Add `game_targeting`, `game_events`, and `launch_events` when you choose the game IDs to support.
- Add hotkeys under `manifest.json > data.hotkeys` for overlay show/hide behavior.
